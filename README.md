**CreditWise Loan Predictor**

Developed an end-to-end machine learning web application for loan approval prediction using Python, Scikit\-learn, and Streamlit. 
Performed data preprocessing, feature engineering, model training with Gaussian Naive Bayes, and deployed the application on Streamlit Cloud. 
The system enables users to enter applicant details and receive instant loan approval predictions through an interactive web interface.
